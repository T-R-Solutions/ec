# Templates de feature

Use estes modelos conforme a [rota escolhida](../workflow.md). Na rota completa,
adapte spec, plan, tasks e converge; na rota local, reutilize o registro existente.
Checklists e ADRs são opcionais. Remova seções irrelevantes sem ocultar requisitos.

Os modelos são instruções de preenchimento, não evidência ou critérios aprovados.
A prosa produzida segue as convenções do [AGENTS.md](../../AGENTS.md).
Referências a arquivos nos modelos partem da raiz do repositório para continuarem
válidas ao copiar o template para uma feature.

Rastreabilidade manual pode permanecer em tabelas Markdown. Para usar o validador,
adicione `traceability.json` e `evidence.json` segundo o
[contrato de evidência](../evidence.md); o formato automatizado não é pré-requisito
para aplicar o método. O acionamento de checks segue a
[política de verificação](../../docs/development/task-verification.md).
