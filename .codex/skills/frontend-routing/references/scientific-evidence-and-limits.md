**Scientific research informs test priorities and UX hypotheses; standards and Vue Router documentation define API semantics. Do not treat browser-user studies as verification of this package's code, the Vue Router runtime, or Ec.**

1. **Cockburn & McKenzie (2001)**, *What do web users do? An empirical analysis of web use*. International Journal of Human-Computer Studies 54(6), 903–922. DOI: [10.1006/ijhc.2001.0459](https://doi.org/10.1006/ijhc.2001.0459). Four-month client-side logs of browser use showed that revisitation was a substantial part of observed behavior. **Relevance:** do not break links/history arbitrarily; test revisits. **Limit:** older Netscape-era sample and browsers; not a modern SPA performance study.
2. **Cockburn, McKenzie & JasonSmith (2002)**, *Pushing back: evaluating a new behaviour for the back and forward buttons in web browsers*. International Journal of Human-Computer Studies 57(5), 397–414 (publisher listing). DOI: [10.1006/ijhc.2002.1025](https://doi.org/10.1006/ijhc.2002.1025). Compared browser Back/Forward alternatives and found task-dependent tradeoffs: temporal history can help some distant revisit tasks while impairing parent backtracking. **Relevance:** history behavior must be tested against task type, not assumed optimal. **Limit:** browser-control experiment, not Vue Router.
3. **Obendorf, Weinreich, Herder & Mayer (2007)**, *Web Page Revisitation Revisited: Implications of a Long-term Click-stream Study of Browser Usage*. CHI 2007 (peer-reviewed ACM conference). Available [author/archive PDF](https://citeseerx.ist.psu.edu/document?doi=689e25029490d93f646c0d3e4eb42a7642526c42&repid=rep1&type=pdf). Studied revisitation and the challenges of recovering prior pages. **Relevance:** keep stable navigational identity and task context. **Limit:** old browsing patterns and not a controlled SPA-routing implementation trial.
4. **Weinreich et al. (2008)**, *Not quite the average: An empirical study of Web use*. ACM Transactions on the Web 2(1), Article 5. DOI: [10.1145/1326561.1326566](https://doi.org/10.1145/1326561.1326566). A longitudinal study reports changing patterns, including decreasing prominence of Back and more multi-tab/service interactions relative to older studies. **Relevance:** counters the assumption that a single Back-centric model describes all modern flows. **Limit:** small longitudinal sample; do not extrapolate measured frequencies to target users.
5. **Rutishauser & Fritz (2026)**, *From Tabs to Structures: Understanding and Supporting Web Page Management*. CHI 2026, Article 1447. DOI: [10.1145/3772318.3791979](https://doi.org/10.1145/3772318.3791979). Field experiment with 29 knowledge workers explored evolving structures and organization of web pages. **Relevance:** contextual navigation and workspace state may require user research, not only routing correctness. **Limit:** a technology probe about page management, not a Vue Router or CI/CD benchmark.

**Evidence classification:** journal/conference empirical observations = study-specific findings; link/route UX decisions = engineering inferences; performance claims for target application = NOT MEASURED; fixture test results = locally observed; real application behavior = NOT VERIFIED until integrated.
