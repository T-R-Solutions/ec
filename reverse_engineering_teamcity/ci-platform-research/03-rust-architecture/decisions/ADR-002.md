# ADR-002 — Fila SQL e PostgreSQL

Status: proposta recomendada para implementação. Data: 2026-10-30.

Requisitos: R03 R05 R10.

Alternativas: PostgreSQL versus SQLite versus broker externo.

Decisão: PostgreSQL para controle; SQLite opcional para laboratório de processo único.

Justificativa independente: Reservas concorrentes e durabilidade exigem transações; SQL evita coordenar broker e estado. SQLite reduz operação mas escritor único limita cenário multiworker.

Consequências e limitações: Operar backup, pool e migrações; não introduzir event sourcing ou outbox no CORE.

Validação: cenários associados aos requisitos em requirements.json e gates do plano incremental.
Fontes: ../components/technology-evaluation.md e ../../01-teamcity-research/evidence/sources.md.
Revisar quando workload, modelo de ameaça ou SLO contradisser a hipótese de implantação.
