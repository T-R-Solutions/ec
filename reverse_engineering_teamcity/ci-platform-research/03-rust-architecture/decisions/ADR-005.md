# ADR-005 — JSON declarativo e DAG

Status: proposta recomendada para implementação. Data: 2026-10-30.

Requisitos: R02 R14 R20.

Alternativas: JSON versus YAML versus TOML versus DSL Rust e UI geradora.

Decisão: JSON v1 canônico como contrato inicial; UI/TOML podem gerar o mesmo IR depois.

Justificativa independente: Sem código arbitrário no controle; parser único reduz ambiguidade; DAG separado do formato.

Consequências e limitações: JSON é verboso; DSL Rust exigiria compilação externa e política de confiança.

Validação: cenários associados aos requisitos em requirements.json e gates do plano incremental.
Fontes: ../components/technology-evaluation.md e ../../01-teamcity-research/evidence/sources.md.
Revisar quando workload, modelo de ameaça ou SLO contradisser a hipótese de implantação.
