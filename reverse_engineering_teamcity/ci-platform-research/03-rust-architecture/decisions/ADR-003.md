# ADR-003 — HTTP JSON e TLS

Status: proposta recomendada para implementação. Data: 2026-10-30.

Requisitos: R04 R05 R07.

Alternativas: HTTP JSON versus Tonic/gRPC versus protocolo privado.

Decisão: HTTP versionado com pull/long poll e chunks binários; TLS Rustls no agente.

Justificativa independente: Inspeção e retries simples no piloto; gRPC só se contratos gerados/streaming comprovarem benefício.

Consequências e limitações: Mais validação manual de schema e overhead JSON; sem alegação de desempenho.

Validação: cenários associados aos requisitos em requirements.json e gates do plano incremental.
Fontes: ../components/technology-evaluation.md e ../../01-teamcity-research/evidence/sources.md.
Revisar quando workload, modelo de ameaça ou SLO contradisser a hipótese de implantação.
